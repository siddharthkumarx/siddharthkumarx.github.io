# siddharthkumar.com

My website. I build and maintain web scrapers for e-commerce price and availability data.

Plain HTML and CSS on GitHub Pages: no build step, no plugins, no forms.

| Path | What it is |
|---|---|
| `index.html` | Home page |
| `work/[project-name]/` | One folder per case study |
| `404.html` | Page shown for broken links |
| `assets/style.css` | All styles, including the animation timing |
| `assets/fonts/` | Instrument Sans and IBM Plex Mono (SIL Open Font License) |
| `assets/og.png` | Link preview picture |
| `CNAME` | Serves this site at siddharthkumar.com |
| `.nojekyll` | Serves the files exactly as they are |
